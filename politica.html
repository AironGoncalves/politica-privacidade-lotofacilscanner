📋 1. Introdução

O aplicativo LotoFacilScanner ("nós", "nosso" ou "aplicativo") respeita sua privacidade e está comprometido em proteger suas informações pessoais. Esta Política de Privacidade descreve como coletamos, usamos, armazenamos e protegemos seus dados quando você utiliza nosso aplicativo.

✅ Resumo Rápido

Coletamos apenas o identificador anônimo do dispositivo para controle do período de teste gratuito. Nenhum dado pessoal (nome, e-mail, localização) é coletado.

🔒 2. Coleta de Dados

Nosso aplicativo coleta APENAS o identificador anônimo do dispositivo (ANDROID_ID) para controle do período de teste gratuito de 7 dias.

📁 Dados armazenados localmente (no seu dispositivo):

  • Jogos cadastrados pelo usuário (números apostados)
  • Histórico de conferências
  • Estatísticas de premiações
  • Slots de memória (jogos salvos nos slots A, B, C, D, E)
  • Controle financeiro (valores de gastos e ganhos inseridos pelo usuário)

☁️ Dados armazenados na nuvem (Firebase Firestore):

🔍 Único dado coletado na nuvem:

ANDROID_ID - Identificador anônimo do dispositivo, utilizado exclusivamente para verificar se o período de teste gratuito de 7 dias já foi utilizado.

  • O que coletamos: Apenas o ID anônimo do dispositivo (ANDROID_ID)
  • O que NÃO coletamos: Nome, e-mail, localização, contatos, fotos, histórico de navegação ou qualquer outro dado pessoal
  • Finalidade exclusiva: Controle do período de teste gratuito (impedir que o mesmo dispositivo utilize o teste mais de uma vez)
  • Armazenamento: Firebase Firestore (Google Cloud Platform)
  • Tempo de retenção: O identificador é mantido apenas para controle do trial, sem prazo de expiração automática

📱 O ANDROID_ID é um identificador gerado pelo sistema Android que não contém informações pessoais e pode ser redefinido pelo usuário nas configurações do dispositivo.

⚙️ 3. Uso de Dados

Como não coletamos dados pessoais, não utilizamos suas informações para:

  • Marketing ou publicidade direcionada
  • Compartilhamento com terceiros
  • Criação de perfis de usuário

Os dados armazenados localmente são utilizados exclusivamente para o funcionamento do aplicativo, permitindo:

  • Conferência de jogos
  • Cálculo de premiações
  • Controle financeiro pessoal
  • Geração de estatísticas de acertos

🔄 4. Compartilhamento de Dados

Não compartilhamos nenhum dado com terceiros. O identificador anônimo do dispositivo é armazenado exclusivamente no Firebase Firestore (Google Cloud) e não é compartilhado com nenhuma outra empresa, serviço ou indivíduo.

Não utilizamos serviços de análise, rastreamento ou publicidade que coletem informações dos usuários.

🌐 5. Conexões com Serviços Externos

O aplicativo utiliza os seguintes serviços externos para seu funcionamento:

📡 APIs de Resultados de Loterias:

Chamadas a APIs públicas e gratuitas para obter resultados oficiais das loterias. Estas chamadas não enviam nenhum dado pessoal.

loteriascaixa-api.herokuapp.com api-loteria.vercel.app

☁️ Firebase (Google):

Firebase Firestore

Serviço de banco de dados em nuvem do Google utilizado exclusivamente para armazenar o identificador anônimo do dispositivo (ANDROID_ID) para controle do período de teste gratuito.

Nenhum dado pessoal é enviado ao Firebase. Consulte a Política de Privacidade do Firebase e os Termos de Serviço do Firebase.

💳 Google Play Billing:

Google Play Billing

Serviço de cobrança do Google utilizado para processar assinaturas. Os dados de pagamento são processados diretamente pelo Google e não são acessados pelo nosso aplicativo. Consulte a Política de Privacidade do Google Payments.

⚠️ Os serviços externos podem coletar dados conforme suas próprias políticas de privacidade. Recomendamos consultar as políticas de cada serviço para mais informações.

🛡️ 6. Segurança

Adotamos medidas de segurança para proteger seus dados:

  • O identificador do dispositivo é transmitido de forma segura (HTTPS)
  • Os dados locais dependem da segurança do seu dispositivo
  • Não armazenamos senhas ou informações sensíveis

Recomendamos:

  • Manter seu dispositivo e sistema operacional atualizados
  • Não compartilhar seu dispositivo com pessoas não autorizadas
  • Utilizar bloqueio de tela em seu dispositivo

👨‍👩‍👧 7. Dados de Menores de Idade

Nosso aplicativo não coleta dados de menores de 18 anos. O uso do aplicativo é recomendado apenas para maiores de idade, conforme exigido pela legislaiseira para apostas em loterias.

🔞 APOSTAR É PARA MAIORES DE 18 ANOS

Este aplicativo é destinado exclusivamente para usuários maiores de idade.
